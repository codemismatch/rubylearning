Chapter 16 – Ruby Blocks Beginner

Learn how Ruby blocks capture context, pass arguments via `yield`, and use block-local variables to avoid clobbering outer state.

> Adapted from Satish Talim's original Ruby Blocks lesson. Blocks (closures) are chunks of code wrapped in {} or do..end that travel alongside method calls. Ruby captures the surrounding context (locals, self, etc.) and lets methods invoke the block with yield.

Block syntax and precedence

  • Use {} for single-line blocks, do..end for multi-line. - {} has higher precedence; do..end binds to the method call even without parentheses. Be explicit when in doubt.
    ruby.rb 
    [1, 2, 3].each { |n| puts n }
[1, 2, 3].each do |n|
  puts n
end

    Yielding to a block

    Any method can take an implicit block. Call it with yield:
    ruby.rb 
    # p022codeblock.rb
def call_block
  puts "Start of method"
  yield
  yield
  puts "End of method"
end

call_block { puts "In the block" }
    If no block is provided and you call yield, Ruby raises LocalJumpError. Guard with block_given?.

    Passing arguments to a block

    yield accepts arguments; list block parameters between pipes:
    ruby.rb 
    # p023codeblock2.rb
def call_block
  yield("hello", 99)
end

call_block { |str, num| puts "#{str} #{num}" }

    Checking for a block

    ruby.rb 
    def try
  if block_given?
    yield
  else
    puts "no block"
  end
end

try                      #=> "no block"
try { puts "hello" }     #=> "hello"
try do puts "hello" end  #=> "hello"

    Blocks capture scope

    Block parameters are local to the block, but referencing outer variables mutates them unless you deliberately shadow them.
    ruby.rb 
    x = 10
5.times do |x|
  puts "x inside block: #{x}"
end
puts "x outside block: #{x}" # 10 -- outer x untouched
    Reassigning x inside the block without using it as a parameter will change the outer variable:
    ruby.rb 
    x = 10
5.times do |y|
  x = y
end
puts x # 4 -- last iteration value
    Ruby 1.9+ introduced block-local variables to avoid accidental clobbering:
    ruby.rb 
    x = 10
5.times do |y; x|
  x = y
  puts "block-local x: #{x}"
end
puts "outer x: #{x}" # 10
    The semicolon separates block parameters (y) from block-local variables (x).
